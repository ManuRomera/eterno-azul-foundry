# Eterno Azul para Foundry VTT

Sistema nativo de aventura y navegación celeste. **Desarrollo en curso: todavía no hay release validada.**

Proyecto no oficial. No requiere Custom System Builder ni módulos de terceros.

Motor de Desafíos, Bríos, Vínculos, daño, hojas V2 y consola naval. Consulta [PROJECT_STATUS.md](PROJECT_STATUS.md) para el estado real y [auditoría de reglas](docs/RULES-MAPPING.md).

## Desarrollo

Node.js 22 o superior. `npm ci`, `npm test`, `npm run check`, `npm run build`.

Código y SVG propios bajo MIT. Los PDF y el arte de Eterno Azul no se redistribuyen. Obtén los materiales en [Shadowlands](https://shadowlands.es/descargas/).
