# Mapa de reglas

Fuente principal: [Guía de inicio oficial](https://shadowlands.es/wp-content/uploads/2026/07/Eterno-Azul_Guia-de-inicio.pdf). Páginas impresas (PDF = impresa + 1). Consulta privada; se implementan procedimientos, no se redistribuye el documento.

| Área | Fuente | Decisión |
|---|---|---|
| Acciones/Señas | pp.7–10 | d6 base Acción; Seña d8–12, fallback d6; escala d4 a d12 |
| Reserva | pp.9–10 | Copias aditivas; aumento al menor/reducción al mayor; topes añaden Ventaja/Riesgo |
| Ventaja | p.10 | d6 por fuente, impedir duplicados de categoría salvo autorización explícita |
| Éxitos/Riesgo | p.11 | 4–7=1, 8–12=2; cero exige DJ, empate o inferior con éxitos tiene consecuencia |
| Bravata | p.12 | +1 Ventaja y consecuencia pactada adicional; elección narrativa |
| Condiciones | pp.13–14 | Intensidad; resistencia estricta, empate conserva efecto hasta fin de duración |
| Bríos | p.17 | Repetir, reducir consecuencia, elemento narrativo, activar Aptitud; fallo voluntario recupera 1 |
| Vínculos | p.8 | Se usa un vínculo propio para ayudar al OTRO PJ; +1 éxito y agotamiento |
| Bulto | p.8 | 10 espacios; ligeros 0,5; agotados consumibles liberan espacio; herramientas persistentes |
| Daño | pp.17,19 | Reducciones sucesivas a mitad, redondeo inferior, Defensa consumible; fuera de combate solo al superar Aguante |
| Heridas | p.19 | Gravedad 1+daño; tres espacios; cuarta implica muerte, presentar decisión; reducción contextual |
| Recuperación | p.19 | Respiro resta mitad de daño (redondeo inferior); descanso limpia daño y reduce heridas 1; Brío a 1 si cero |
| Navíos | pp.20–21 | Maniobra y Vela comparadas; Navegar para maniobrar/perseguir; Combatir para artillería |
| Artillería | p.21 | Potencia + margen, mitad Potencia en proa/popa; mitad total en seguimiento; no gastar munición por disparo |
| Persecución | p.20 | Cuatro distancias más escape; alternativas requieren aceptar consecuencia |
| Iniciativa | p.15 | Orden narrativo o Desafío; tracker opcional, sin fórmula d20 |

Discrepancias: resumen p.14 dice -1 Intensidad pero texto y ejemplo p.13 dicen -1 por éxito: prevalece texto explicado. Resistencia enemiga p.16 dice 1+margen mientras p.13 dice margen: ofrecer ambas decisiones explícitas, no automatizar elección. Daño que cruza Aguante: ejemplo p.19 produce derrota sin Herida hasta siguiente ataque; se sigue ese ejemplo, dejando Herida directa/voluntaria explícita.

No disponibles en Guía: asignación completa de creación, catálogo completo de Orígenes/Arquetipos, magia ritual completa, reglas de carga y reparación naval/Entretiempo. Modelos extensibles; ninguna tabla inventada.
